## Python — Variables

| Syntax / Keyword | Name                       | Definition                                      | Example              |
| ---------------- | -------------------------- | ----------------------------------------------- | -------------------- |
| `=`              | Assignment Operator        | Assigns a value to a variable                   | `age = 25`           |
| `variable`       | Variable                   | A name that refers to a value/object            | `name = "John"`      |
| `x = y`          | Assignment                 | Assigns the value/reference of `y` to `x`       | `x = y`              |
| `x, y = 1, 2`    | Multiple Assignment        | Assigns multiple values at once                 | `x, y = 1, 2`        |
| `x = y = 0`      | Chained Assignment         | Assigns the same value to multiple variables    | `x = y = 0`          |
| `x, y = y, x`    | Multiple Assignment / Swap | Swaps variable values                           | `x, y = y, x`        |
| `+=`             | Add & Assign               | Adds and assigns                                | `x += 5`             |
| `-=`             | Subtract & Assign          | Subtracts and assigns                           | `x -= 5`             |
| `*=`             | Multiply & Assign          | Multiplies and assigns                          | `x *= 5`             |
| `/=`             | Divide & Assign            | Divides and assigns                             | `x /= 5`             |
| `//=`            | Floor Divide & Assign      | Floor-divides and assigns                       | `x //= 5`            |
| `%=`             | Modulus & Assign           | Gets remainder and assigns                      | `x %= 5`             |
| `**=`            | Exponent & Assign          | Raises to a power and assigns                   | `x **= 2`            |
| `del`            | Delete Variable            | Removes a variable reference                    | `del x`              |
| `type()`         | Type Check                 | Returns the type of the value                   | `type(x)`            |
| `id()`           | Object Identity            | Returns the object's identity                   | `id(x)`              |
| `isinstance()`   | Type Testing               | Checks whether a value is an instance of a type | `isinstance(x, int)` |

### Example

```python id="b7gq4s"
name = "John"
age = 25

age += 1

print(name)
print(age)
```

### Important

Python variables **don't have a fixed type**:

```python id="f4k9qn"
x = 10
x = "Hello"
x = [1, 2, 3]
```

The **object/value has a type**, and the variable refers to that object.
