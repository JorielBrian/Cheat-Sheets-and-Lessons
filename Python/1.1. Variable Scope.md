## Python — Variable Scope

**Scope** determines **where a variable can be accessed** in your code.

| Keyword / Concept | Name             | Definition                                                             | Example                     |
| ----------------- | ---------------- | ---------------------------------------------------------------------- | --------------------------- |
| Global            | Global Scope     | Variable defined outside functions; accessible throughout the module   | `x = 10`                    |
| Local             | Local Scope      | Variable defined inside a function; only accessible there              | `def test(): x = 10`        |
| Enclosing         | Enclosing Scope  | Variable in an outer function accessible by an inner function          | `def outer(): x = 10`       |
| Built-in          | Built-in Scope   | Names provided by Python itself                                        | `print()`, `len()`, `int()` |
| `global`          | Global Keyword   | Allows a function to modify a global variable                          | `global x`                  |
| `nonlocal`        | Nonlocal Keyword | Allows an inner function to modify a variable in an enclosing function | `nonlocal x`                |

### LEGB Rule

Python searches for variables in this order:

```text
L → Local
E → Enclosing
G → Global
B → Built-in
```

Example:

```python id="3n0x1v"
x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)

    inner()

outer()
```

Output:

```text
local
```

### `global`

```python id="3j1w2q"
count = 0

def increase():
    global count
    count += 1

increase()

print(count)  # 1
```

### `nonlocal`

```python id="h6r9sp"
def outer():
    count = 0

    def increase():
        nonlocal count
        count += 1

    increase()
    print(count)

outer()
```

Output:

```text
1
```

**Remember:** A variable's scope determines **where Python can find and access it**.
