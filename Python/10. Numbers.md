## Python Number Data Types

| Keyword   | Name                  | Definition                                                    | Example           |
| --------- | --------------------- | ------------------------------------------------------------- | ----------------- |
| `int`     | Integer               | Whole numbers, positive or negative                           | `age = 25`        |
| `float`   | Floating-Point Number | Numbers with decimal values                                   | `price = 19.99`   |
| `complex` | Complex Number        | Numbers containing a real and imaginary part                  | `z = 3 + 4j`      |
| `bool`    | Boolean               | Represents `True` or `False`; technically a subclass of `int` | `is_valid = True` |

### Examples

```python
x = 10          # int
y = 10.5        # float
z = 3 + 4j      # complex
active = True   # bool
```

You can check their types with:

```python
print(type(x))
print(type(y))
print(type(z))
print(type(active))
```

Output:

```text
<class 'int'>
<class 'float'>
<class 'complex'>
<class 'bool'>
```
## Python Number Built-in Functions

| Function       | Name               | Definition                                 | Example                        |
| -------------- | ------------------ | ------------------------------------------ | ------------------------------ |
| `abs()`        | Absolute Value     | Returns the positive magnitude of a number | `abs(-10)` → `10`              |
| `round()`      | Round              | Rounds a number                            | `round(3.7)` → `4`             |
| `pow()`        | Power              | Raises a number to a power                 | `pow(2, 3)` → `8`              |
| `min()`        | Minimum            | Returns the smallest value                 | `min(3, 1, 5)` → `1`           |
| `max()`        | Maximum            | Returns the largest value                  | `max(3, 1, 5)` → `5`           |
| `sum()`        | Sum                | Adds values in an iterable                 | `sum([1, 2, 3])` → `6`         |
| `divmod()`     | Division & Modulus | Returns quotient and remainder             | `divmod(10, 3)` → `(3, 1)`     |
| `int()`        | Convert to Integer | Converts a value to an integer             | `int("10")` → `10`             |
| `float()`      | Convert to Float   | Converts a value to a float                | `float("10.5")` → `10.5`       |
| `complex()`    | Convert to Complex | Creates a complex number                   | `complex(2, 3)` → `(2+3j)`     |
| `bin()`        | Binary             | Converts an integer to binary              | `bin(10)` → `'0b1010'`         |
| `oct()`        | Octal              | Converts an integer to octal               | `oct(10)` → `'0o12'`           |
| `hex()`        | Hexadecimal        | Converts an integer to hexadecimal         | `hex(10)` → `'0xa'`            |
| `isinstance()` | Type Check         | Checks whether a value belongs to a type   | `isinstance(10, int)` → `True` |

These are **built-in functions**, so you don't need to import a module to use them.
