## Python `Enum`

`Enum` is used to create a set of **named constant values**.

> Unlike `int`, `float`, etc., `Enum` isn't a built-in data type by itself. You import it from Python's `enum` module.

```python
from enum import Enum
```

### Enum Basics

| Keyword / Syntax   | Name              | Definition                                   | Example                    |
| ------------------ | ----------------- | -------------------------------------------- | -------------------------- |
| `Enum`             | Enum class        | Base class for creating enumerations         | `class Color(Enum):`       |
| `enum`             | Enum module       | Module containing `Enum` and related classes | `from enum import Enum`    |
| `class`            | Class definition  | Defines your custom enumeration              | `class Color(Enum):`       |
| `=`                | Member assignment | Assigns a value to an enum member            | `RED = 1`                  |
| `Color.RED`        | Enum member       | Accesses a specific member                   | `print(Color.RED)`         |
| `.name`            | Member name       | Gets the member's name                       | `Color.RED.name` → `"RED"` |
| `.value`           | Member value      | Gets the member's assigned value             | `Color.RED.value` → `1`    |
| `list()`           | Get all members   | Converts the Enum into a list of members     | `list(Color)`              |
| `EnumClass(value)` | Lookup by value   | Finds the member with a specific value       | `Color(1)` → `Color.RED`   |

### Example

```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 3

print(Color.RED)
print(Color.RED.name)
print(Color.RED.value)
```

Output:

```text
Color.RED
RED
1
```

You can also compare members:

```python
if color == Color.RED:
    print("The color is red")
```

Enums are useful when you have a **fixed set of possible choices**, such as:

```python
class Status(Enum):
    PENDING = 1
    APPROVED = 2
    REJECTED = 3
```
