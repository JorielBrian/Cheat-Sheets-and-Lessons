## Python User Input

| Function / Syntax | Name               | Definition                                | Example                           |
| ----------------- | ------------------ | ----------------------------------------- | --------------------------------- |
| `input()`         | User Input         | Gets input from the user as a **string**  | `name = input("Name: ")`          |
| `input("...")`    | Input Prompt       | Displays a message before accepting input | `input("Enter age: ")`            |
| `int()`           | Convert to Integer | Converts input to an integer              | `age = int(input("Age: "))`       |
| `float()`         | Convert to Float   | Converts input to a decimal number        | `price = float(input("Price: "))` |
| `str()`           | Convert to String  | Converts a value to a string              | `name = str(123)`                 |
| `.strip()`        | Remove Whitespace  | Removes spaces around the user's input    | `name = input().strip()`          |
| `.lower()`        | Lowercase          | Converts input to lowercase               | `choice = input().lower()`        |
| `.upper()`        | Uppercase          | Converts input to uppercase               | `choice = input().upper()`        |

### Basic example

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print(f"Hello, {name}!")
print(f"You are {age} years old.")
```

**Important:** `input()` always returns a **string**.

```python
age = input("Age: ")

print(type(age))
# <class 'str'>
```

That's why you use `int()` or `float()` when you need numerical input.
