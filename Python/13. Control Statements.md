## Python — Control Statements

| Keyword / Syntax | Name            | Definition                                         | Example              |
| ---------------- | --------------- | -------------------------------------------------- | -------------------- |
| `if`             | Conditional     | Executes code when a condition is true             | `if age >= 18:`      |
| `elif`           | Else If         | Checks another condition                           | `elif age >= 13:`    |
| `else`           | Else            | Executes when all previous conditions are false    | `else:`              |
| `for`            | For Loop        | Repeats code for each item in a sequence           | `for x in numbers:`  |
| `while`          | While Loop      | Repeats code while a condition is true             | `while x < 10:`      |
| `break`          | Break           | Immediately exits a loop                           | `break`              |
| `continue`       | Continue        | Skips the current iteration and continues the loop | `continue`           |
| `pass`           | Pass            | Does nothing; used as a placeholder                | `pass`               |
| `match`          | Match Statement | Compares a value against different patterns        | `match choice:`      |
| `case`           | Case            | Defines a pattern inside `match`                   | `case "rock":`       |
| `return`         | Return          | Exits a function and optionally returns a value    | `return result`      |
| `raise`          | Raise           | Stops normal execution by raising an exception     | `raise ValueError()` |

### Main categories

```text
Conditional
├── if
├── elif
└── else

Loops
├── for
└── while

Loop Control
├── break
├── continue
└── pass

Pattern Matching
├── match
└── case

Function Control
├── return
└── raise
```
