## Python — `if` Statements

| Keyword / Syntax | Name         | Definition                                                    | Example                             |
| ---------------- | ------------ | ------------------------------------------------------------- | ----------------------------------- |
| `if`             | If Statement | Executes code when a condition is `True`                      | `if age >= 18:`                     |
| `elif`           | Else If      | Checks another condition if the previous condition is `False` | `elif age >= 13:`                   |
| `else`           | Else         | Executes when all previous conditions are `False`             | `else:`                             |
| `:`              | Colon        | Starts the code block for the condition                       | `if x > 5:`                         |
| Indentation      | Code Block   | Defines which code belongs to the condition                   | `if x > 5:`<br>    `print(x)`       |
| `and`            | Logical AND  | Requires all conditions to be `True`                          | `if age >= 18 and age < 60:`        |
| `or`             | Logical OR   | Requires at least one condition to be `True`                  | `if age < 18 or age > 60:`          |
| `not`            | Logical NOT  | Reverses a condition                                          | `if not logged_in:`                 |
| Nested `if`      | Nested If    | An `if` statement inside another `if`                         | `if age >= 18:`<br>    `if has_id:` |

### Basic example

```python id="4i5u6r"
age = 20

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teenager")
else:
    print("Child")
```

**Important:** Python uses **indentation** instead of `{}` to define the code block.

## Python — Refactoring Nested `if`

**Refactoring** means restructuring code to make it **simpler, cleaner, or easier to maintain** without changing what it does.

### Common techniques

| Syntax / Technique     | Name                   | Definition                                   | Example                                      |
| ---------------------- | ---------------------- | -------------------------------------------- | -------------------------------------------- |
| `and`                  | Combine Conditions     | Combines nested conditions into one          | `if age >= 18 and has_id:`                   |
| `or`                   | Alternative Conditions | Combines conditions where either can be true | `if admin or owner:`                         |
| `elif`                 | Multiple Conditions    | Replaces unnecessary nested `if` statements  | `if x > 10` → `elif x > 5`                   |
| `not`                  | Negation               | Reverses a condition                         | `if not logged_in:`                          |
| Early Return           | Guard Clause           | Exits a function early instead of nesting    | `if not valid: return`                       |
| Conditional Expression | Ternary                | Simplifies a simple `if/else`                | `status = "Adult" if age >= 18 else "Minor"` |

### Nested version

```python id="0l8fxy"
if age >= 18:
    if has_id:
        print("Allowed")
```

### Refactored version

```python id="q5s7bd"
if age >= 18 and has_id:
    print("Allowed")
```

Another example:

```python id="p5j8nd"
if age >= 18:
    if has_id:
        if verified:
            print("Allowed")
```

Can become:

```python id="1j3k8s"
if age >= 18 and has_id and verified:
    print("Allowed")
```

The goal isn't to **always eliminate nesting**. Sometimes nested `if` statements are clearer, especially when the conditions represent separate logical steps.
