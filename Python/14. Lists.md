## Python — Lists

| Syntax / Method         | Name             | Definition                             | Example                           |
| ----------------------- | ---------------- | -------------------------------------- | --------------------------------- |
| `[]`                    | List             | Creates an ordered, mutable collection | `numbers = [1, 2, 3]`             |
| `list()`                | List Constructor | Creates a list from an iterable        | `list("abc")` → `['a', 'b', 'c']` |
| `list[index]`           | Indexing         | Accesses an item by its position       | `numbers[0]` → `1`                |
| `list[-1]`              | Negative Index   | Accesses items from the end            | `numbers[-1]` → `3`               |
| `list[start:stop]`      | Slicing          | Gets a portion of a list               | `numbers[1:3]`                    |
| `list[start:stop:step]` | Extended Slicing | Slices using a step                    | `numbers[::2]`                    |
| `.append()`             | Append           | Adds one item to the end               | `numbers.append(4)`               |
| `.insert()`             | Insert           | Adds an item at a specific position    | `numbers.insert(1, 10)`           |
| `.extend()`             | Extend           | Adds multiple items                    | `numbers.extend([4, 5])`          |
| `.remove()`             | Remove           | Removes the first matching item        | `numbers.remove(2)`               |
| `.pop()`                | Pop              | Removes and returns an item            | `numbers.pop()`                   |
| `.clear()`              | Clear            | Removes all items                      | `numbers.clear()`                 |
| `.index()`              | Index            | Finds the position of an item          | `numbers.index(2)`                |
| `.count()`              | Count            | Counts occurrences of an item          | `numbers.count(2)`                |
| `.sort()`               | Sort             | Sorts the list in place                | `numbers.sort()`                  |
| `.reverse()`            | Reverse          | Reverses the list in place             | `numbers.reverse()`               |
| `.copy()`               | Copy             | Creates a shallow copy                 | `new = numbers.copy()`            |
| `len()`                 | Length           | Returns the number of items            | `len(numbers)`                    |
| `in`                    | Membership       | Checks whether an item exists          | `2 in numbers`                    |
| `not in`                | Not Membership   | Checks whether an item doesn't exist   | `5 not in numbers`                |
| `del`                   | Delete           | Removes an item or slice               | `del numbers[0]`                  |
| `+`                     | Concatenation    | Combines two lists                     | `[1, 2] + [3, 4]`                 |
| `*`                     | Repetition       | Repeats a list                         | `[1, 2] * 2`                      |

### List Comprehension

| Syntax                                           | Name                           | Definition                           | Example                         |
| ------------------------------------------------ | ------------------------------ | ------------------------------------ | ------------------------------- |
| `[expression for item in iterable]`              | List Comprehension             | Creates a list using a compact loop  | `[x * 2 for x in numbers]`      |
| `[expression for item in iterable if condition]` | Conditional List Comprehension | Creates a list while filtering items | `[x for x in numbers if x > 2]` |

### Example

```python
numbers = [1, 2, 3]

numbers.append(4)
numbers.remove(2)

print(numbers)
# [1, 3, 4]
```
## Python — Ways to Get Values from a List

| Syntax / Method            | Name                  | Definition                         | Example                               |
| -------------------------- | --------------------- | ---------------------------------- | ------------------------------------- |
| `list[index]`              | Indexing              | Gets one value using its index     | `fruits[0]` → `"apple"`               |
| `list[-1]`                 | Negative Indexing     | Gets a value from the end          | `fruits[-1]` → `"orange"`             |
| `list[start:stop]`         | Slicing               | Gets multiple values               | `fruits[0:2]` → `["apple", "banana"]` |
| `list[start:stop:step]`    | Extended Slicing      | Gets values using a step           | `numbers[::2]` → `[1, 3, 5]`          |
| `for item in list`         | Iteration             | Gets each value one at a time      | `for fruit in fruits:`                |
| `enumerate()`              | Value + Index         | Gets both index and value          | `for i, fruit in enumerate(fruits):`  |
| `.index()`                 | Find by Value         | Gets the index of a specific value | `fruits.index("banana")` → `1`        |
| `list[0]`, `list[1]`, etc. | Specific Value        | Directly accesses a known position | `numbers[2]` → `30`                   |
| `list.pop()`               | Get & Remove          | Gets and removes an item           | `last = numbers.pop()`                |
| `list.pop(index)`          | Get & Remove by Index | Gets and removes a specific item   | `numbers.pop(1)`                      |

### Example

```python id="t3s6wy"
fruits = ["apple", "banana", "orange", "mango"]
```

**Get one:**

```python
fruits[1]       # banana
```

**Get multiple:**

```python
fruits[1:3]     # ['banana', 'orange']
```

**Get every item:**

```python
for fruit in fruits:
    print(fruit)
```

**Get index + value:**

```python
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

**Find a value's position:**

```python
fruits.index("orange")  # 2
```
## Python — Sorting Lists

| Method / Function           | Name            | Definition                                                  | Example                         |
| --------------------------- | --------------- | ----------------------------------------------------------- | ------------------------------- |
| `.sort()`                   | Sort Method     | Sorts the original list in ascending order                  | `numbers.sort()`                |
| `.sort(reverse=True)`       | Reverse Sort    | Sorts the original list in descending order                 | `numbers.sort(reverse=True)`    |
| `sorted()`                  | Sorted Function | Returns a **new sorted list** without changing the original | `sorted(numbers)`               |
| `sorted(..., reverse=True)` | Reverse Sorted  | Returns a new list in descending order                      | `sorted(numbers, reverse=True)` |
| `.sort(key=...)`            | Custom Sort     | Sorts based on a custom rule                                | `names.sort(key=len)`           |
| `sorted(key=...)`           | Custom Sorted   | Creates a new list using a custom rule                      | `sorted(names, key=len)`        |

### `.sort()` vs `sorted()`

```python id="vry4ck"
numbers = [3, 1, 5, 2]

numbers.sort()

print(numbers)
# [1, 2, 3]
```

`.sort()` **changes the original list**.

```python id="q1m6k2"
numbers = [3, 1, 5, 2]

new_numbers = sorted(numbers)

print(numbers)      # [3, 1, 5, 2]
print(new_numbers)  # [1, 2, 3]
```

`sorted()` **keeps the original list unchanged**.
