## Python — Adding & Removing Values from Lists

### Adding Values

| Method      | Name              | Definition                        | Example                  |
| ----------- | ----------------- | --------------------------------- | ------------------------ |
| `.append()` | Append            | Adds one item to the end          | `numbers.append(4)`      |
| `.insert()` | Insert            | Adds one item at a specific index | `numbers.insert(1, 10)`  |
| `.extend()` | Extend            | Adds multiple items               | `numbers.extend([4, 5])` |
| `+`         | Concatenation     | Combines lists into a new list    | `numbers + [4, 5]`       |
| `+=`        | Extend Assignment | Adds items to the existing list   | `numbers += [4, 5]`      |

### Removing Values

| Method / Keyword | Name                  | Definition                              | Example             |
| ---------------- | --------------------- | --------------------------------------- | ------------------- |
| `.remove()`      | Remove by Value       | Removes the first matching value        | `numbers.remove(3)` |
| `.pop()`         | Remove by Index       | Removes and returns an item             | `numbers.pop()`     |
| `.pop(index)`    | Remove Specific Index | Removes and returns an item at an index | `numbers.pop(1)`    |
| `del`            | Delete                | Removes an item or range                | `del numbers[1]`    |
| `.clear()`       | Clear                 | Removes all items                       | `numbers.clear()`   |

### Example

```python
numbers = [10, 20, 30]

numbers.append(40)       # [10, 20, 30, 40]
numbers.insert(1, 15)    # [10, 15, 20, 30, 40]
numbers.remove(20)       # [10, 15, 30, 40]
numbers.pop()            # [10, 15, 30]
del numbers[0]           # [15, 30]
```

**Key difference:**

* `remove()` → remove **by value**
* `pop()` → remove **by index** and return the removed value
* `del` → delete by **index or slice**
* `clear()` → remove **everything**
