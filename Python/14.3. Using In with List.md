## Using `in` with Lists

`in` checks whether a **value exists inside a list**.

```python
fruits = ["apple", "banana", "orange"]

print("apple" in fruits)   # True
print("mango" in fruits)   # False
```

### With `not in`

```python
fruits = ["apple", "banana", "orange"]

print("mango" not in fruits)  # True
```

### Common use with `if`

```python
fruits = ["apple", "banana", "orange"]

if "banana" in fruits:
    print("Banana is available")
```

You can also use it with numbers:

```python
numbers = [10, 20, 30, 40]

if 20 in numbers:
    print("20 exists")
```

**Remember:**

```text
in      → Does this value exist in the list?
not in  → Does this value NOT exist in the list?
```
