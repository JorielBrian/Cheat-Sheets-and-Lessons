## Python — Array vs List vs Tuple

> In Python, **list** and **tuple** are built-in types. `array` usually refers to the `array` module's `array.array`.

| Feature                           | List                | Tuple             | Array                   |
| --------------------------------- | ------------------- | ----------------- | ----------------------- |
| Type                              | `list`              | `tuple`           | `array.array`           |
| Ordered                           | ✅                   | ✅                 | ✅                       |
| Mutable                           | ✅                   | ❌                 | ✅                       |
| Can change values                 | ✅                   | ❌                 | ✅                       |
| Can add/remove                    | ✅                   | ❌                 | ✅                       |
| Different data types              | ✅                   | ✅                 | ❌ Usually same type     |
| Memory efficient                  | ❌                   | ✅ More than list  | ✅ More than list        |
| Type restriction                  | ❌                   | ❌                 | ✅                       |
| Indexing                          | ✅                   | ✅                 | ✅                       |
| Slicing                           | ✅                   | ✅                 | ✅                       |
| `.append()`                       | ✅                   | ❌                 | ✅                       |
| `.remove()`                       | ✅                   | ❌                 | ✅                       |
| `.count()`                        | ✅                   | ✅                 | ✅                       |
| `.index()`                        | ✅                   | ✅                 | ✅                       |
| Mathematical/numerical operations | Limited             | Limited           | Better suited           |
| Common use                        | General collections | Fixed collections | Numeric data            |
| Built-in                          | ✅                   | ✅                 | Requires `array` import |

### Examples

**List**

```python
numbers = [1, 2, 3, "hello"]
numbers.append(4)
```

**Tuple**

```python
coordinates = (10, 20)
# coordinates[0] = 50  ❌
```

**Array**

```python
from array import array

numbers = array("i", [1, 2, 3])
numbers.append(4)
```

`"i"` specifies the type of elements—in this case, **signed integers**.

### When to use each

| Situation                                    | Use       |
| -------------------------------------------- | --------- |
| General-purpose collection                   | **List**  |
| Data should not change                       | **Tuple** |
| Large collection of same-type numeric values | **Array** |

### Easy way to remember

```text
List   → Flexible
Tuple  → Fixed
Array  → Same-type numbers
```

For most everyday Python programming, you'll use **lists and tuples far more often than `array.array`**.
