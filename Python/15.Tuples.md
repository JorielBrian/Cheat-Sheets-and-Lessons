## Python — Tuples

| Syntax / Method     | Name              | Definition                               | Example               |
| ------------------- | ----------------- | ---------------------------------------- | --------------------- |
| `()`                | Tuple             | Creates an ordered, immutable collection | `numbers = (1, 2, 3)` |
| `tuple()`           | Tuple Constructor | Creates a tuple from an iterable         | `tuple([1, 2, 3])`    |
| `tuple[index]`      | Indexing          | Accesses an item by its index            | `numbers[0]` → `1`    |
| `tuple[-1]`         | Negative Indexing | Accesses an item from the end            | `numbers[-1]` → `3`   |
| `tuple[start:stop]` | Slicing           | Gets a portion of a tuple                | `numbers[1:3]`        |
| `len()`             | Length            | Returns the number of items              | `len(numbers)`        |
| `.count()`          | Count             | Counts occurrences of a value            | `numbers.count(2)`    |
| `.index()`          | Index             | Returns the index of a value             | `numbers.index(2)`    |
| `in`                | Membership        | Checks whether a value exists            | `2 in numbers`        |
| `not in`            | Not Membership    | Checks whether a value doesn't exist     | `5 not in numbers`    |
| `+`                 | Concatenation     | Combines tuples                          | `(1, 2) + (3, 4)`     |
| `*`                 | Repetition        | Repeats a tuple                          | `(1, 2) * 2`          |
| `del`               | Delete            | Deletes the entire tuple variable        | `del numbers`         |

### Important

Tuples are **immutable**, meaning you cannot change their individual values:

```python id="k8n0zx"
numbers = (1, 2, 3)

numbers[0] = 10  # ❌ TypeError
```

But you can create a **new tuple**:

```python id="0w4fna"
numbers = (1, 2, 3)
numbers = (10, 2, 3)
```

### Tuple unpacking

```python id="q1r8m7"
person = ("John", 25)

name, age = person

print(name)  # John
print(age)   # 25
```

A tuple is commonly useful when you have a collection of values that **should not be changed**.
