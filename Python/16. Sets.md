## Python — Sets

A **set** is an **unordered collection of unique values**.

| Syntax / Method           | Name                  | Definition                                        | Example                        |          |
| ------------------------- | --------------------- | ------------------------------------------------- | ------------------------------ | -------- |
| `{}`                      | Empty Set             | ⚠️ `{}` creates an empty dictionary, not a set    | `set()`                        |          |
| `{value1, value2}`        | Set                   | Creates a set of unique values                    | `{1, 2, 3}`                    |          |
| `set()`                   | Set Constructor       | Creates an empty set or converts an iterable      | `set([1, 2, 2])` → `{1, 2}`    |          |
| `in`                      | Membership            | Checks if a value exists                          | `2 in numbers`                 |          |
| `not in`                  | Not Membership        | Checks if a value doesn't exist                   | `5 not in numbers`             |          |
| `.add()`                  | Add                   | Adds one value                                    | `numbers.add(4)`               |          |
| `.update()`               | Add Multiple          | Adds multiple values                              | `numbers.update([4, 5])`       |          |
| `.remove()`               | Remove                | Removes a value; raises an error if absent        | `numbers.remove(3)`            |          |
| `.discard()`              | Safe Remove           | Removes a value without an error if absent        | `numbers.discard(3)`           |          |
| `.pop()`                  | Remove Arbitrary Item | Removes and returns an arbitrary item             | `numbers.pop()`                |          |
| `.clear()`                | Clear                 | Removes all values                                | `numbers.clear()`              |          |
| `.copy()`                 | Copy                  | Creates a shallow copy                            | `new = numbers.copy()`         |          |
| `len()`                   | Length                | Returns the number of values                      | `len(numbers)`                 |          |
| `                         | `                     | Union                                             | Combines values from both sets | `a \| b` |
| `.union()`                | Union                 | Combines two or more sets                         | `a.union(b)`                   |          |
| `&`                       | Intersection          | Gets values present in both sets                  | `a & b`                        |          |
| `.intersection()`         | Intersection          | Gets common values                                | `a.intersection(b)`            |          |
| `-`                       | Difference            | Gets values only in the first set                 | `a - b`                        |          |
| `.difference()`           | Difference            | Gets values only in the first set                 | `a.difference(b)`              |          |
| `^`                       | Symmetric Difference  | Gets values that aren't shared                    | `a ^ b`                        |          |
| `.symmetric_difference()` | Symmetric Difference  | Gets non-common values                            | `a.symmetric_difference(b)`    |          |
| `<=`                      | Subset                | Checks if all values exist in another set         | `a <= b`                       |          |
| `<`                       | Proper Subset         | Checks if it's a subset but not equal             | `a < b`                        |          |
| `>=`                      | Superset              | Checks if it contains another set                 | `a >= b`                       |          |
| `>`                       | Proper Superset       | Checks if it contains another set and isn't equal | `a > b`                        |          |
| `.issubset()`             | Subset Check          | Checks whether one set is a subset                | `a.issubset(b)`                |          |
| `.issuperset()`           | Superset Check        | Checks whether one set is a superset              | `a.issuperset(b)`              |          |
| `.isdisjoint()`           | Disjoint Check        | Checks whether two sets have no common values     | `a.isdisjoint(b)`              |          |

### Example

```python
numbers = {1, 2, 3, 3, 4}

print(numbers)
```

Output:

```text
{1, 2, 3, 4}
```

The duplicate `3` is automatically removed.

### Set operations

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # {1, 2, 3, 4, 5}
print(a & b)  # {3}
print(a - b)  # {1, 2}
print(a ^ b)  # {1, 2, 4, 5}
```

**Remember:**

```text
List  → ordered, allows duplicates
Tuple → ordered, immutable, allows duplicates
Set   → unordered, unique values
```
