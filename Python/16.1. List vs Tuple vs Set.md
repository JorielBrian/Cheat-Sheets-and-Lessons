## Python — List vs Tuple vs Set

| Feature                     | List                                  | Tuple            | Set                                 |
| --------------------------- | ------------------------------------- | ---------------- | ----------------------------------- |
| Type                        | `list`                                | `tuple`          | `set`                               |
| Ordered                     | ✅ Yes                                 | ✅ Yes            | ❌ No guaranteed positional order    |
| Mutable                     | ✅ Yes                                 | ❌ No             | ✅ Yes                               |
| Allows duplicates           | ✅ Yes                                 | ✅ Yes            | ❌ No                                |
| Indexing                    | ✅                                     | ✅                | ❌                                   |
| Slicing                     | ✅                                     | ✅                | ❌                                   |
| Add items                   | `.append()`, `.insert()`, `.extend()` | ❌                | `.add()`, `.update()`               |
| Remove items                | `.remove()`, `.pop()`, `del`          | ❌                | `.remove()`, `.discard()`, `.pop()` |
| Search with `in`            | ✅                                     | ✅                | ✅                                   |
| `.index()`                  | ✅                                     | ✅                | ❌                                   |
| `.count()`                  | ✅                                     | ✅                | ❌                                   |
| Set operations              | ❌                                     | ❌                | ✅                                   |
| Union `\|`                  | ❌                                     | ❌                | ✅                                   |
| Intersection `&`            | ❌                                     | ❌                | ✅                                   |
| Difference `-`              | ❌                                     | ❌                | ✅                                   |
| Can contain different types | ✅                                     | ✅                | ✅*                                  |
| Hashable                    | ❌                                     | ✅*               | ❌                                   |
| Common purpose              | General collection                    | Fixed collection | Unique values / set operations      |

* Set elements must be **hashable**. A tuple is hashable only when its contents are hashable.

### Example

```python
my_list = [1, 2, 2, 3]

my_tuple = (1, 2, 2, 3)

my_set = {1, 2, 2, 3}
```

Result:

```text
list  → [1, 2, 2, 3]
tuple → (1, 2, 2, 3)
set   → {1, 2, 3}
```

### When to use

| Need                               | Use               |
| ---------------------------------- | ----------------- |
| Collection that you need to modify | **List**          |
| Collection that shouldn't change   | **Tuple**         |
| Unique values / remove duplicates  | **Set**           |
| Need indexing like `[0]`           | **List or Tuple** |
| Need mathematical set operations   | **Set**           |
| Need to preserve duplicate values  | **List or Tuple** |

### Easy way to remember

> **List = ordered + changeable + duplicates**
> **Tuple = ordered + unchangeable + duplicates**
> **Set = unique values + no positional indexing**
