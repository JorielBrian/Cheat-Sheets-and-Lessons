## Python — Closures

A **closure** occurs when an inner function **remembers and accesses variables from its enclosing function**, even after the outer function has finished executing.

| Syntax / Concept   | Name                     | Definition                                                | Example               |
| ------------------ | ------------------------ | --------------------------------------------------------- | --------------------- |
| Nested `def`       | Inner Function           | Function defined inside another function                  | `def inner():`        |
| `return inner`     | Return Function          | Returns the inner function itself                         | `return inner`        |
| Enclosing variable | Captured Variable        | Variable remembered by the inner function                 | `x = 10`              |
| Closure            | Closure                  | Inner function + remembered enclosing variables           | `add = make_adder(5)` |
| `nonlocal`         | Modify Captured Variable | Allows the inner function to change an enclosing variable | `nonlocal count`      |
| `__closure__`      | Closure Information      | Accesses the closure's captured variables                 | `func.__closure__`    |

### Basic example

```python
def outer():
    message = "Hello"

    def inner():
        print(message)

    return inner


my_function = outer()

my_function()
```

Output:

```text
Hello
```

Even though `outer()` has already finished, `inner()` **remembers `message`**.

### Practical example

```python
def multiplier(x):

    def multiply(y):
        return x * y

    return multiply


double = multiplier(2)
triple = multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15
```

Here:

```text
double → remembers x = 2
triple → remembers x = 3
```

### Closure with `nonlocal`

```python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase


counter1 = counter()

print(counter1())  # 1
print(counter1())  # 2
print(counter1())  # 3
```

`count` is **preserved between calls** because the closure remembers it.

### Simple way to remember

> **Closure = a function that remembers variables from where it was created.**
