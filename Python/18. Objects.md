## Python — Objects

In Python, **everything is an object** (numbers, strings, lists, functions, classes, etc.). An object has a **type**, **data/state**, and potentially **behavior/methods**.

| Syntax / Concept | Name                    | Definition                                            | Example                    |
| ---------------- | ----------------------- | ----------------------------------------------------- | -------------------------- |
| `object`         | Object                  | An instance of a type/class                           | `x = 10`                   |
| `class`          | Class                   | Blueprint used to create objects                      | `class User:`              |
| `Class()`        | Instance Creation       | Creates an object from a class                        | `user = User()`            |
| `attribute`      | Attribute               | Data associated with an object                        | `user.name`                |
| `method`         | Method                  | Function associated with an object                    | `user.greet()`             |
| `self`           | Instance Reference      | Refers to the current object inside its methods       | `self.name`                |
| `__init__()`     | Constructor/Initializer | Initializes an object's attributes when created       | `def __init__(self):`      |
| `type()`         | Type                    | Gets the object's type                                | `type(user)`               |
| `isinstance()`   | Instance Check          | Checks whether an object belongs to a type/class      | `isinstance(user, User)`   |
| `id()`           | Object Identity         | Gets the object's identity                            | `id(user)`                 |
| `is`             | Identity Comparison     | Checks whether two variables refer to the same object | `a is b`                   |
| `__dict__`       | Object Namespace        | Shows an object's stored attributes when available    | `user.__dict__`            |
| `hasattr()`      | Attribute Check         | Checks whether an object has an attribute             | `hasattr(user, "name")`    |
| `getattr()`      | Get Attribute           | Gets an attribute dynamically                         | `getattr(user, "name")`    |
| `setattr()`      | Set Attribute           | Creates or changes an attribute dynamically           | `setattr(user, "age", 25)` |
| `delattr()`      | Delete Attribute        | Deletes an attribute dynamically                      | `delattr(user, "age")`     |

### Basic Object Example

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"My name is {self.name}"


user = User("John", 25)

print(user.name)
print(user.age)
print(user.introduce())
```

Here:

```text
User          → class
user          → object / instance
user.name     → attribute
user.age      → attribute
user.introduce() → method
```

### Objects can be many things

```python
number = 10
text = "Hello"
numbers = [1, 2, 3]
user = User("John", 25)
```

All of these are objects:

```text
10          → int object
"Hello"     → str object
[1, 2, 3]   → list object
user        → User object
```

**Core idea:**

> **Class = blueprint**
> **Object = instance created from that blueprint**
> **Attribute = object's data**
> **Method = object's behavior**
