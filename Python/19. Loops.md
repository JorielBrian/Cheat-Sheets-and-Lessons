## Python — Loops

Loops allow you to **repeat code** multiple times.

| Syntax / Keyword | Name               | Definition                                   | Example                          |
| ---------------- | ------------------ | -------------------------------------------- | -------------------------------- |
| `for`            | For Loop           | Iterates through each item in an iterable    | `for x in numbers:`              |
| `while`          | While Loop         | Repeats while a condition is `True`          | `while x < 5:`                   |
| `in`             | Iteration Operator | Specifies the iterable to loop through       | `for x in numbers:`              |
| `range()`        | Range              | Generates a sequence of numbers              | `for i in range(5):`             |
| `break`          | Break              | Immediately exits the loop                   | `break`                          |
| `continue`       | Continue           | Skips the current iteration                  | `continue`                       |
| `else`           | Loop Else          | Runs when the loop finishes normally         | `for x in numbers: ... else:`    |
| `enumerate()`    | Enumerate          | Provides both index and value                | `for i, x in enumerate(items):`  |
| `zip()`          | Zip                | Iterates through multiple iterables together | `for a, b in zip(x, y):`         |
| Nested Loop      | Nested Loop        | A loop inside another loop                   | `for x in a:`<br>  `for y in b:` |

### `for` loop

```python id="8k7y4p"
fruits = ["apple", "banana", "orange"]

for fruit in fruits:
    print(fruit)
```

### `while` loop

```python id="w3l4kx"
count = 0

while count < 3:
    print(count)
    count += 1
```

### `range()`

```python id="j9b3x2"
for i in range(5):
    print(i)
```

Output:

```text id="m0r1nc"
0
1
2
3
4
```

### `break` and `continue`

```python id="6z8g5n"
for i in range(10):
    if i == 5:
        break
    print(i)
```

`break` → **stops the loop completely**

```python id="8t2w6q"
for i in range(5):
    if i == 2:
        continue
    print(i)
```

`continue` → **skips that iteration and continues**

### Simple distinction

> **`for` → iterate through a collection/sequence**
> **`while` → repeat while a condition remains true**
