## Python — `break` and `continue`

Both are **loop control statements**, but they behave differently.

| Keyword    | Name               | Definition                                                | Example               |
| ---------- | ------------------ | --------------------------------------------------------- | --------------------- |
| `break`    | Break Statement    | Immediately **stops and exits** the loop                  | `if x == 3: break`    |
| `continue` | Continue Statement | **Skips the current iteration** and moves to the next one | `if x == 3: continue` |

### `break`

```python
for i in range(5):
    if i == 3:
        break
    print(i)
```

Output:

```text
0
1
2
```

When `i == 3`, the entire loop stops.

---

### `continue`

```python
for i in range(5):
    if i == 3:
        continue
    print(i)
```

Output:

```text
0
1
2
4
```

When `i == 3`, Python **skips that iteration**, then continues with `4`.

### Visual difference

```text
break
1 → 2 → 3 → STOP

continue
1 → 2 → 3 → SKIP → 4 → 5
```

**Remember:**

> `break` = **leave the loop**
> `continue` = **skip this iteration**
