# Python Functions

| Keyword / Syntax | Name                          | Definition                                               | Example                     |
| ---------------- | ----------------------------- | -------------------------------------------------------- | --------------------------- |
| `def`            | Define Function               | Creates a function                                       | `def greet():`              |
| `()`             | Parameters                    | Holds parameters passed to a function                    | `def greet(name):`          |
| `return`         | Return                        | Sends a value back from the function                     | `return result`             |
| `function()`     | Function Call                 | Executes a function                                      | `greet()`                   |
| `*args`          | Variable Positional Arguments | Accepts multiple positional arguments                    | `def add(*args):`           |
| `**kwargs`       | Variable Keyword Arguments    | Accepts multiple keyword arguments                       | `def user(**kwargs):`       |
| `lambda`         | Lambda Function               | Creates a small anonymous function                       | `square = lambda x: x ** 2` |
| `pass`           | Empty Statement               | Does nothing; useful as a placeholder                    | `def test(): pass`          |
| `global`         | Global Keyword                | Allows a function to modify a global variable            | `global count`              |
| `nonlocal`       | Nonlocal Keyword              | Allows an inner function to modify an enclosing variable | `nonlocal count`            |

### Function example

```python
def add(a, b):
    result = a + b
    return result

answer = add(5, 3)

print(answer)
```

Here:

```text
a, b       → parameters
5, 3       → arguments
return     → sends the result back
add(5, 3)  → function call
```
## Python — Calling Functions

| Syntax / Keyword       | Name                     | Definition                                     | Example              |
| ---------------------- | ------------------------ | ---------------------------------------------- | -------------------- |
| `function()`           | Function Call            | Executes a function                            | `greet()`            |
| `function(value)`      | Argument                 | Passes a value to a parameter                  | `greet("John")`      |
| `function(a, b)`       | Multiple Arguments       | Passes multiple values                         | `add(5, 3)`          |
| `function(name=value)` | Keyword Argument         | Passes a value using the parameter name        | `greet(name="John")` |
| `function(*args)`      | Unpack Arguments         | Unpacks a list/tuple into positional arguments | `add(*numbers)`      |
| `function(**kwargs)`   | Unpack Keyword Arguments | Unpacks a dictionary into keyword arguments    | `user(**data)`       |
| `result = function()`  | Store Return Value       | Stores the returned value in a variable        | `total = add(5, 3)`  |
| `print(function())`    | Use Return Value         | Directly uses the returned value               | `print(add(5, 3))`   |

### Example

```python id="q1b7y9"
def greet(name):
    return f"Hello, {name}!"

message = greet("John")

print(message)
```

Output:

```text
Hello, John!
```

**Key distinction:**

```python id="6qj6py"
def greet(name):   # defining the function
    return name

greet("John")      # calling the function
```

`def` **creates** the function; `()` **calls/executes** it.

## Python — Function Arguments

| Syntax             | Name                           | Definition                                       | Example                    |
| ------------------ | ------------------------------ | ------------------------------------------------ | -------------------------- |
| `def func(x)`      | Parameter                      | Variable that receives a value                   | `def greet(name):`         |
| `func(value)`      | Positional Argument            | Value passed based on position                   | `greet("John")`            |
| `func(name=value)` | Keyword Argument               | Value passed using the parameter name            | `greet(name="John")`       |
| `*args`            | Arbitrary Positional Arguments | Accepts any number of positional arguments       | `def add(*args):`          |
| `**kwargs`         | Arbitrary Keyword Arguments    | Accepts any number of keyword arguments          | `def user(**kwargs):`      |
| `param=value`      | Default Parameter              | Provides a default value if no argument is given | `def greet(name="Guest"):` |
| `*`                | Keyword-only Separator         | Makes following parameters keyword-only          | `def user(name, *, age):`  |
| `/`                | Positional-only Separator      | Makes preceding parameters positional-only       | `def add(x, /, y):`        |
| `*list`            | Argument Unpacking             | Unpacks a list/tuple into positional arguments   | `add(*numbers)`            |
| `**dict`           | Keyword Unpacking              | Unpacks a dictionary into keyword arguments      | `user(**data)`             |

### Example

```python id="zqf6mg"
def greet(name, age=18):
    print(f"{name} is {age}")

greet("John", 25)
greet(name="Jane", age=30)
greet("Bob")
```

Output:

```text
John is 25
Jane is 30
Bob is 18
```

**Important distinction:**

```text
Parameter = variable in the function definition
Argument = actual value you pass to the function
```

```python id="h0u9wt"
def greet(name):   # name = parameter
    print(name)

greet("John")       # "John" = argument
```
