## Python — Nested Functions

A **nested function** is a function defined **inside another function**.

| Syntax / Keyword   | Name              | Definition                                                             | Example                     |
| ------------------ | ----------------- | ---------------------------------------------------------------------- | --------------------------- |
| `def` inside `def` | Nested Function   | Defines a function inside another function                             | `def outer(): def inner():` |
| `outer()`          | Outer Function    | The function containing the nested function                            | `def outer():`              |
| `inner()`          | Inner Function    | The function defined inside the outer function                         | `def inner():`              |
| `nonlocal`         | Nonlocal Variable | Allows the inner function to modify a variable from the outer function | `nonlocal count`            |
| Closure            | Closure           | Inner function remembers variables from its enclosing function         | `return inner`              |
| `return inner`     | Return Function   | Returns the nested function itself                                     | `return inner`              |

### Basic example

```python id="5p6k4s"
def outer():
    def inner():
        print("Hello from inner")

    inner()

outer()
```

Output:

```text
Hello from inner
```

### Nested function accessing an outer variable

```python id="r7h2xq"
def outer():
    message = "Hello"

    def inner():
        print(message)

    inner()

outer()
```

The `inner()` function can access `message` because of **enclosing scope**.

### Closure example

```python id="g4y8qn"
def multiplier(x):

    def multiply(y):
        return x * y

    return multiply

double = multiplier(2)

print(double(5))
```

Output:

```text
10
```

Here, `multiply()` **remembers `x`**, even after `multiplier()` has finished.

### Why use nested functions?

Common purposes:

* **Encapsulation** — keep a helper function private to another function
* **Closures** — remember values from an outer function
* **Decorators** — Python decorators commonly use nested functions
* **Helper functions** — organize complex logic inside a function

**Simple idea:**

```text
outer()
 └── inner()
```

The `inner()` function only exists within the scope where it is defined.
