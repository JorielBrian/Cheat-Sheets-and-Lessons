# Python — Classes

A **class** is a blueprint for creating objects. It defines the **data (attributes)** and **behavior (methods)** that its objects can have.

| Keyword / Syntax      | Name               | Definition                                                | Example                   |
| --------------------- | ------------------ | --------------------------------------------------------- | ------------------------- |
| `class`               | Class Definition   | Creates a class                                           | `class User:`             |
| `Class()`             | Instance           | Creates an object from a class                            | `user = User()`           |
| `__init__()`          | Initializer        | Runs automatically when an object is created              | `def __init__(self):`     |
| `self`                | Instance Reference | Refers to the current object                              | `self.name = name`        |
| `attribute`           | Instance Attribute | Data belonging to an object                               | `self.name = "John"`      |
| `method`              | Instance Method    | Function belonging to an object                           | `user.greet()`            |
| `@classmethod`        | Class Method       | Method that receives the class as `cls`                   | `@classmethod`            |
| `cls`                 | Class Reference    | Refers to the class inside a class method                 | `cls.count`               |
| `@staticmethod`       | Static Method      | Method that doesn't automatically receive `self` or `cls` | `@staticmethod`           |
| `class attribute`     | Class Attribute    | Data shared by the class/instances                        | `species = "Human"`       |
| `super()`             | Parent Access      | Accesses methods/attributes from a parent class           | `super().__init__()`      |
| `class Child(Parent)` | Inheritance        | Creates a class based on another class                    | `class Admin(User):`      |
| `isinstance()`        | Instance Check     | Checks whether an object belongs to a class               | `isinstance(user, User)`  |
| `issubclass()`        | Class Check        | Checks whether a class inherits from another              | `issubclass(Admin, User)` |

### Basic class

```python id="y1v6oe"
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"Hi, I'm {self.name}")


user = User("John", 25)

print(user.name)
user.introduce()
```

Here:

```text
User              → class
user              → object / instance
name, age         → attributes
introduce()       → method
__init__()        → initializer
self              → current object
```

### Class Attribute

```python id="j3p8fr"
class User:
    species = "Human"

    def __init__(self, name):
        self.name = name

user1 = User("John")
user2 = User("Jane")

print(user1.species)
print(user2.species)
```

Both objects can access the same **class attribute**.

### Inheritance

```python id="c8r4vx"
class User:
    def introduce(self):
        print("Hello")


class Admin(User):
    def delete_user(self):
        print("User deleted")


admin = Admin()

admin.introduce()
admin.delete_user()
```

`Admin` **inherits** the behavior of `User`.

### Simple way to remember

> **Class = blueprint**
> **Object = thing created from the blueprint**
> **Attribute = data**
> **Method = behavior**
> **Inheritance = reuse/extend another class**
