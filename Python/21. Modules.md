# Python — Modules

A **module** is a Python file (`.py`) containing code—such as functions, classes, and variables—that can be reused in another Python file.

| Keyword / Syntax  | Name                 | Definition                                   | Example                      |
| ----------------- | -------------------- | -------------------------------------------- | ---------------------------- |
| `.py`             | Python Module        | A Python file that can be imported           | `math_utils.py`              |
| `import`          | Import               | Imports a module                             | `import math`                |
| `from ... import` | Import Specific Item | Imports specific functions/classes/variables | `from math import sqrt`      |
| `as`              | Alias                | Gives an imported module/item another name   | `import math as m`           |
| `module.name`     | Module Member        | Accesses something inside a module           | `math.sqrt(25)`              |
| `__name__`        | Module Name          | Contains the module's name                   | `print(__name__)`            |
| `__main__`        | Main Module          | Indicates the file is being run directly     | `if __name__ == "__main__":` |
| `dir()`           | List Members         | Shows names available in a module/object     | `dir(math)`                  |
| `help()`          | Documentation        | Displays documentation about a module/object | `help(math)`                 |

### Creating your own module

**`math_utils.py`**

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b
```

**`main.py`**

```python
import math_utils

print(math_utils.add(5, 3))
```

Output:

```text
8
```

### Importing specific functions

```python
from math_utils import add

print(add(5, 3))
```

### Using an alias

```python
import math_utils as math

print(math.add(5, 3))
```

### `__name__ == "__main__"`

Very commonly used in Python modules:

```python
def greet():
    print("Hello")


if __name__ == "__main__":
    greet()
```

This means:

> Run `greet()` **only when this file is executed directly**, not when it is imported by another file.

### Module vs Library

|         | Module                      | Library                                 |
| ------- | --------------------------- | --------------------------------------- |
| Meaning | Usually a single `.py` file | Collection of reusable modules/packages |
| Example | `random`                    | NumPy                                   |
| Purpose | Organize/reuse code         | Provide larger functionality            |

**Simple idea:**

> **Module = reusable Python file**
> **Library = collection of reusable code**
