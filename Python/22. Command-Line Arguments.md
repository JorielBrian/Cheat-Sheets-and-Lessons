# Python — Command-Line Arguments

Command-line arguments are **values passed to a Python program when you run it from the terminal**.

For example:

```bash
python app.py John 25
```

Here, `John` and `25` are command-line arguments.

| Syntax / Keyword   | Name            | Definition                                                           | Example                              |
| ------------------ | --------------- | -------------------------------------------------------------------- | ------------------------------------ |
| `sys.argv`         | Argument List   | Contains the command-line arguments                                  | `sys.argv`                           |
| `sys.argv[0]`      | Script Name     | Contains the name/path of the Python script                          | `sys.argv[0]`                        |
| `sys.argv[1]`      | First Argument  | Gets the first argument after the script name                        | `sys.argv[1]`                        |
| `sys.argv[2]`      | Second Argument | Gets the second argument                                             | `sys.argv[2]`                        |
| `len(sys.argv)`    | Argument Count  | Gets the number of command-line arguments                            | `len(sys.argv)`                      |
| `argparse`         | Argument Parser | Standard library module for handling command-line arguments properly | `import argparse`                    |
| `ArgumentParser()` | Parser          | Creates an argument parser                                           | `parser = argparse.ArgumentParser()` |
| `.add_argument()`  | Define Argument | Defines an argument your program accepts                             | `parser.add_argument("name")`        |
| `.parse_args()`    | Parse Arguments | Reads and processes the supplied arguments                           | `args = parser.parse_args()`         |

### Basic `sys.argv` example

**app.py**

```python
import sys

print(sys.argv)
```

Run:

```bash
python app.py John 25
```

Output:

```python
['app.py', 'John', '25']
```

Notice that **all command-line arguments are strings**.

```python
name = sys.argv[1]
age = int(sys.argv[2])
```

---

## Using `argparse`

For more serious programs, `argparse` is usually better:

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("name")
parser.add_argument("age", type=int)

args = parser.parse_args()

print(args.name)
print(args.age)
```

Run:

```bash
python app.py John 25
```

Output:

```text
John
25
```

### Why use command-line arguments?

They allow you to give your program **different inputs without modifying the code**.

```bash
python calculator.py 10 20
python calculator.py 100 50
python calculator.py 500 250
```

**Simple distinction:**

> `input()` → user enters data **while the program is running**
> Command-line arguments → data is provided **when starting the program**
