# Python — Lambda Functions

A **lambda function** is a small **anonymous function** written in a single expression.

| Syntax / Keyword       | Name                 | Definition                               | Example              |
| ---------------------- | -------------------- | ---------------------------------------- | -------------------- |
| `lambda`               | Lambda Function      | Creates an anonymous function            | `lambda x: x * 2`    |
| `lambda x:`            | Parameter            | Defines the input parameter              | `lambda x: x + 1`    |
| `:`                    | Expression Separator | Separates parameters from the expression | `lambda x: x * 2`    |
| `lambda x: expression` | Lambda Syntax        | General lambda function structure        | `lambda x: x ** 2`   |
| `lambda x, y:`         | Multiple Parameters  | Lambda can accept multiple parameters    | `lambda x, y: x + y` |
| `lambda x=10:`         | Default Parameter    | Allows a default parameter value         | `lambda x=10: x * 2` |

### Basic example

```python id="n8jv4w"
square = lambda x: x ** 2

print(square(5))
```

Output:

```text
25
```

Equivalent regular function:

```python id="x9y7cb"
def square(x):
    return x ** 2
```

### Multiple parameters

```python id="v3h4qn"
add = lambda x, y: x + y

print(add(5, 3))
```

Output:

```text
8
```

### Common use: `sorted()`

```python id="d8q2mk"
names = ["John", "Alexander", "Bob"]

names.sort(key=lambda name: len(name))

print(names)
```

Output:

```text
['Bob', 'John', 'Alexander']
```

The lambda tells `sort()` **what value to use for sorting**.

### Important limitation

A lambda can only contain **one expression**:

```python id="h1j3xq"
square = lambda x: x ** 2  # ✅
```

For complex logic, use a normal `def` function instead.

> **`def` → normal, reusable function**
> **`lambda` → short, simple, usually one-time function**
