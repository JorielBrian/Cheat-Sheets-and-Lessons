# Python — `map()`, `filter()`, and `reduce()`

These are functions commonly used with **iterables** such as lists, often together with `lambda`.

| Function   | Name   | Definition                                               | Example                               |
| ---------- | ------ | -------------------------------------------------------- | ------------------------------------- |
| `map()`    | Map    | Applies a function to **every item** in an iterable      | `map(lambda x: x * 2, numbers)`       |
| `filter()` | Filter | Keeps only items where a function returns `True`         | `filter(lambda x: x > 5, numbers)`    |
| `reduce()` | Reduce | Repeatedly combines items to produce **one final value** | `reduce(lambda x, y: x + y, numbers)` |

> `map()` and `filter()` are built-in. `reduce()` must be imported from `functools`.

---

## `map()`

Transforms every item.

```python
numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(list(result))
```

Output:

```text
[2, 4, 6, 8]
```

Think:

> **map → change every item**

---

## `filter()`

Keeps items that satisfy a condition.

```python
numbers = [1, 2, 3, 4, 5, 6]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))
```

Output:

```text
[2, 4, 6]
```

Think:

> **filter → keep what matches**

---

## `reduce()`

Combines items progressively into **one value**.

```python
from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(lambda x, y: x + y, numbers)

print(result)
```

Output:

```text
10
```

Conceptually:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
```

Think:

> **reduce → combine everything into one result**

### Quick comparison

```text
map()    → [1, 2, 3] → [2, 4, 6]
filter() → [1, 2, 3] → [2]       (depending on condition)
reduce() → [1, 2, 3] → 6
```

One important detail: `map()` and `filter()` return **iterators**, so you commonly use `list()` when you want to see/store all their results immediately.
