# Python — Recursion

**Recursion** is when a function **calls itself** to solve a problem by breaking it into smaller versions of the same problem.

| Syntax / Concept           | Name               | Definition                                | Example                                     |
| -------------------------- | ------------------ | ----------------------------------------- | ------------------------------------------- |
| `function()` inside itself | Recursive Call     | Function calls itself                     | `countdown(n - 1)`                          |
| Base Case                  | Stopping Condition | Condition that stops recursion            | `if n == 0: return`                         |
| Recursive Case             | Recursive Step     | Part where the function calls itself      | `countdown(n - 1)`                          |
| `return`                   | Return Value       | Returns the result from a recursive call  | `return n * factorial(n - 1)`               |
| Call Stack                 | Function Stack     | Python keeps track of each recursive call | `factorial(5)` → calls `factorial(4)` → ... |

### Basic example

```python id="jz7a5n"
def countdown(n):
    if n == 0:
        return

    print(n)
    countdown(n - 1)


countdown(5)
```

Output:

```text id="v1p0dj"
5
4
3
2
1
```

### How it works

```text id="6jkw4n"
countdown(5)
    ↓
countdown(4)
    ↓
countdown(3)
    ↓
countdown(2)
    ↓
countdown(1)
    ↓
countdown(0)
    ↓
STOP
```

### Example: Factorial

```python id="z0l0hs"
def factorial(n):
    if n == 1:
        return 1

    return n * factorial(n - 1)


print(factorial(5))
```

Conceptually:

```text id="1f4tqj"
5 × factorial(4)
    ↓
5 × 4 × factorial(3)
    ↓
5 × 4 × 3 × factorial(2)
    ↓
5 × 4 × 3 × 2 × factorial(1)
    ↓
5 × 4 × 3 × 2 × 1
    ↓
120
```

### ⚠️ Important

Every recursive function needs a **base case**.

Without one:

```python
def forever():
    forever()

forever()
```

Python eventually raises:

```text
RecursionError: maximum recursion depth exceeded
```

**Simple way to remember:**

> **Recursion = a function solving a problem by calling itself on a smaller version of the problem.**
