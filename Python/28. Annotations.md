# Python — Annotations

**Annotations** are optional information added to variables, function parameters, and return values. They are commonly used to indicate **expected data types**.

Python generally **does not enforce annotations at runtime**.

| Syntax            | Name                     | Definition                                           | Example               |
| ----------------- | ------------------------ | ---------------------------------------------------- | --------------------- |
| `x: type`         | Variable Annotation      | Indicates the expected type of a variable            | `age: int = 25`       |
| `parameter: type` | Parameter Annotation     | Indicates the expected parameter type                | `def add(a: int):`    |
| `-> type`         | Return Annotation        | Indicates the expected return type                   | `def add() -> int:`   |
| `:`               | Annotation Syntax        | Separates the variable/parameter from its annotation | `name: str`           |
| `->`              | Return Annotation Syntax | Specifies the expected return type                   | `-> float`            |
| `__annotations__` | Annotations Dictionary   | Accesses annotations programmatically                | `add.__annotations__` |

### Variable annotations

```python
name: str = "John"
age: int = 25
price: float = 19.99
active: bool = True
```

### Function annotations

```python
def add(a: int, b: int) -> int:
    return a + b
```

Meaning:

```text
a → expected to be int
b → expected to be int
return → expected to be int
```

### Important: Python doesn't enforce them

```python
def add(a: int, b: int) -> int:
    return a + b

print(add("Hello", " World"))
```

This can still run:

```text
Hello World
```

The annotations are **hints**, not automatic restrictions.

### More complex annotations

```python
def greet(name: str) -> str:
    return f"Hello, {name}"
```

```python
numbers: list[int] = [1, 2, 3]
```

```python
users: dict[str, int] = {
    "John": 25,
    "Jane": 30
}
```

### Why use annotations?

They improve:

* **Readability**
* **IDE/autocomplete support**
* **Static type checking**
* **Code maintenance**
* **Documentation**

> **Annotation = information about the expected type/structure of data.**
