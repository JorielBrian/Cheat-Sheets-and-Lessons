# Python — Exceptions

An **exception** is an error or unexpected event that occurs while a Python program is running. Python can **catch and handle** exceptions instead of immediately stopping the program.

| Keyword / Syntax | Name               | Definition                                       | Example                       |
| ---------------- | ------------------ | ------------------------------------------------ | ----------------------------- |
| `Exception`      | Base Exception     | Base class for most built-in exceptions          | `raise Exception("Error")`    |
| `try`            | Try Block          | Contains code that might cause an exception      | `try: result = 10 / 0`        |
| `except`         | Exception Handler  | Handles an exception                             | `except ZeroDivisionError:`   |
| `else`           | Else Block         | Runs if no exception occurred in `try`           | `else: print("Success")`      |
| `finally`        | Finally Block      | Runs regardless of whether an exception occurred | `finally: print("Done")`      |
| `raise`          | Raise Exception    | Manually triggers an exception                   | `raise ValueError("Invalid")` |
| `as`             | Exception Alias    | Stores the exception object in a variable        | `except ValueError as e:`     |
| `try...except`   | Exception Handling | Prevents an exception from crashing the program  | `try: ... except: ...`        |

### Basic example

```python
try:
    number = int(input("Enter a number: "))
    print(10 / number)

except ValueError:
    print("Please enter a valid number.")

except ZeroDivisionError:
    print("Cannot divide by zero.")
```

### `else`

`else` runs **only when no exception occurs**:

```python
try:
    number = int(input("Enter a number: "))

except ValueError:
    print("Invalid number.")

else:
    print(f"You entered {number}")
```

### `finally`

`finally` **always runs**:

```python
try:
    number = int(input("Enter a number: "))

except ValueError:
    print("Invalid input.")

finally:
    print("Program finished.")
```

### `raise`

You can create your own exception:

```python
age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
```

### Common built-in exceptions

| Exception             | Usually occurs when                         |
| --------------------- | ------------------------------------------- |
| `ValueError`          | Correct type but invalid value              |
| `TypeError`           | Wrong/incompatible data type                |
| `NameError`           | Variable doesn't exist                      |
| `IndexError`          | List index doesn't exist                    |
| `KeyError`            | Dictionary key doesn't exist                |
| `ZeroDivisionError`   | Dividing by zero                            |
| `FileNotFoundError`   | File doesn't exist                          |
| `AttributeError`      | Object doesn't have the requested attribute |
| `ImportError`         | Import cannot be performed                  |
| `ModuleNotFoundError` | Module cannot be found                      |

### Basic structure

```text
try
 ├── code that might fail
 │
 ├── except → handle the error
 │
 ├── else → runs if successful
 │
 └── finally → always runs
```

**Simple way to remember:**

> `try` → attempt
> `except` → handle error
> `else` → success
> `finally` → always execute
> `raise` → create an error yourself
