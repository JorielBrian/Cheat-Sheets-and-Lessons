## Python — Dictionaries

| Syntax / Method     | Name                   | Definition                                                     | Example                    |
| ------------------- | ---------------------- | -------------------------------------------------------------- | -------------------------- |
| `{}`                | Empty Dictionary       | Creates an empty dictionary                                    | `user = {}`                |
| `{"key": value}`    | Dictionary             | Creates key-value pairs                                        | `user = {"name": "John"}`  |
| `dict()`            | Dictionary Constructor | Creates a dictionary                                           | `user = dict(name="John")` |
| `dict[key]`         | Access Value           | Gets a value using its key                                     | `user["name"]`             |
| `dict[key] = value` | Add / Update           | Adds a new key or updates an existing key                      | `user["age"] = 25`         |
| `del`               | Delete                 | Removes a key-value pair                                       | `del user["age"]`          |
| `.get()`            | Get Value              | Gets a value without raising an error if the key doesn't exist | `user.get("age")`          |
| `.keys()`           | Keys                   | Returns all dictionary keys                                    | `user.keys()`              |
| `.values()`         | Values                 | Returns all dictionary values                                  | `user.values()`            |
| `.items()`          | Items                  | Returns key-value pairs                                        | `user.items()`             |
| `.pop()`            | Remove & Return        | Removes a key and returns its value                            | `user.pop("age")`          |
| `.popitem()`        | Remove Last Item       | Removes and returns the last key-value pair                    | `user.popitem()`           |
| `.update()`         | Update Dictionary      | Adds or updates multiple key-value pairs                       | `user.update({"age": 25})` |
| `.clear()`          | Clear                  | Removes all items                                              | `user.clear()`             |
| `.copy()`           | Copy                   | Creates a shallow copy                                         | `new_user = user.copy()`   |
| `len()`             | Length                 | Returns number of key-value pairs                              | `len(user)`                |
| `in`                | Membership             | Checks whether a key exists                                    | `"name" in user`           |
| `not in`            | Not Membership         | Checks whether a key doesn't exist                             | `"email" not in user`      |

### Example

```python id="c1e9q2"
user = {
    "name": "John",
    "age": 25
}

print(user["name"])

user["email"] = "john@example.com"

print(user)
```

### Looping through a dictionary

```python id="k6z7fp"
for key, value in user.items():
    print(key, value)
```

Output:

```text id="7wx3cp"
name John
age 25
email john@example.com
```
## Python — Accessing Dictionary Values

| Syntax / Method      | Name              | Definition                                                     | Example               |
| -------------------- | ----------------- | -------------------------------------------------------------- | --------------------- |
| `dict[key]`          | Key Access        | Gets the value associated with a key                           | `user["name"]`        |
| `.get(key)`          | Get               | Gets a value without raising an error if the key doesn't exist | `user.get("name")`    |
| `.get(key, default)` | Get with Default  | Returns a default value if the key doesn't exist               | `user.get("age", 0)`  |
| `.keys()`            | Keys              | Gets all keys                                                  | `user.keys()`         |
| `.values()`          | Values            | Gets all values                                                | `user.values()`       |
| `.items()`           | Items             | Gets all key-value pairs                                       | `user.items()`        |
| `in`                 | Key Check         | Checks whether a key exists                                    | `"name" in user`      |
| `not in`             | Key Absence Check | Checks whether a key doesn't exist                             | `"email" not in user` |

### Example

```python
user = {
    "name": "John",
    "age": 25
}

print(user["name"])       # John
print(user.get("age"))    # 25
print(user.get("email"))  # None
```

### Important difference

```python
user["email"]       # ❌ KeyError if "email" doesn't exist

user.get("email")   # ✅ Returns None
```

Use `[]` when you **expect the key to exist**. Use `.get()` when the key **might not exist**.
