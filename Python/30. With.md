# Python — `with` Statement

The `with` statement is used for **resource management**. It automatically performs cleanup when you're finished with a resource, even if an exception occurs.

The most common example is **working with files**.

| Syntax / Keyword | Name                      | Definition                                           | Example                       |
| ---------------- | ------------------------- | ---------------------------------------------------- | ----------------------------- |
| `with`           | Context Manager Statement | Manages a resource and automatically handles cleanup | `with open("file.txt") as f:` |
| `as`             | Resource Alias            | Gives the managed resource a variable name           | `as file`                     |
| `__enter__()`    | Enter Method              | Runs when entering the `with` block                  | `def __enter__(self):`        |
| `__exit__()`     | Exit Method               | Runs when leaving the `with` block                   | `def __exit__(self, ...):`    |
| Context Manager  | Resource Manager          | Object that defines `__enter__()` and `__exit__()`   | `open()`                      |

### File example

Without `with`:

```python
file = open("data.txt", "r")

content = file.read()

file.close()
```

With `with`:

```python
with open("data.txt", "r") as file:
    content = file.read()
```

The file is **automatically closed** when the block ends.

### Why is this useful?

```python
with open("data.txt") as file:
    data = file.read()

# file is automatically closed here
```

Even if an exception occurs:

```python
with open("data.txt") as file:
    data = file.read()
    raise ValueError("Something went wrong")
```

Python still performs the context manager's cleanup.

### Common uses

| Resource             | Example                                       |
| -------------------- | --------------------------------------------- |
| Files                | `with open(...) as file:`                     |
| Locks                | `with lock:`                                  |
| Database connections | `with connection:`                            |
| Network resources    | `with ...:`                                   |
| Custom resources     | Objects implementing `__enter__` / `__exit__` |

### Simple way to remember

> **`with` = use a resource safely and automatically clean it up afterward.**
