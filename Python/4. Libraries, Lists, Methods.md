# Python — Libraries

| Syntax / Keyword    | Name              | Definition                              | Example                 |
| ------------------- | ----------------- | --------------------------------------- | ----------------------- |
| `import`            | Import            | Imports a module/library                | `import random`         |
| `from`              | Import From       | Imports a specific item                 | `from math import sqrt` |
| `as`                | Alias             | Gives an imported module another name   | `import numpy as np`    |
| `module.function()` | Module Function   | Uses a function from an imported module | `math.sqrt(25)`         |
| `pip`               | Package Installer | Installs third-party packages           | `pip install requests`  |

### Example

```python
import random

number = random.randint(1, 10)
print(number)
```

# Python — Lists

| Syntax / Method | Name             | Definition                          | Example                  |
| --------------- | ---------------- | ----------------------------------- | ------------------------ |
| `[]`            | List             | Creates a list                      | `numbers = [1, 2, 3]`    |
| `list()`        | List Constructor | Creates a list                      | `numbers = list("abc")`  |
| `[index]`       | Indexing         | Gets an item by position            | `numbers[0]`             |
| `[start:stop]`  | Slicing          | Gets part of a list                 | `numbers[1:3]`           |
| `[-1]`          | Negative Index   | Gets an item from the end           | `numbers[-1]`            |
| `.append()`     | Append           | Adds an item to the end             | `numbers.append(4)`      |
| `.insert()`     | Insert           | Adds an item at a specific position | `numbers.insert(1, 10)`  |
| `.extend()`     | Extend           | Adds multiple items                 | `numbers.extend([4, 5])` |
| `.remove()`     | Remove           | Removes the first matching value    | `numbers.remove(2)`      |
| `.pop()`        | Pop              | Removes and returns an item         | `numbers.pop()`          |
| `.clear()`      | Clear            | Removes all items                   | `numbers.clear()`        |
| `.index()`      | Index            | Finds the position of a value       | `numbers.index(3)`       |
| `.count()`      | Count            | Counts occurrences of a value       | `numbers.count(2)`       |
| `.sort()`       | Sort             | Sorts the list                      | `numbers.sort()`         |
| `.reverse()`    | Reverse          | Reverses the list                   | `numbers.reverse()`      |
| `.copy()`       | Copy             | Creates a shallow copy              | `new = numbers.copy()`   |
| `len()`         | Length           | Returns the number of items         | `len(numbers)`           |
| `in`            | Membership       | Checks whether an item exists       | `2 in numbers`           |

### Example

```python
fruits = ["apple", "banana", "orange"]

fruits.append("mango")
fruits.remove("banana")

print(fruits)
```

# Python — Methods

| Syntax              | Name                    | Definition                                                     | Example                       |
| ------------------- | ----------------------- | -------------------------------------------------------------- | ----------------------------- |
| `object.method()`   | Method Call             | Calls a method belonging to an object                          | `"hello".upper()`             |
| `.method()`         | Instance Method         | Performs an operation on a specific object                     | `numbers.append(5)`           |
| `.method(value)`    | Method with Argument    | Passes data to a method                                        | `numbers.remove(5)`           |
| `.method()` → value | Returning Method        | Method returns a value                                         | `"hello".upper()` → `"HELLO"` |
| `Class.method()`    | Class Method            | Method associated with a class rather than a specific instance | `User.create()`               |
| `@classmethod`      | Class Method Decorator  | Defines a class method                                         | `@classmethod`                |
| `@staticmethod`     | Static Method Decorator | Defines a method that doesn't require instance/class data      | `@staticmethod`               |
| `self`              | Instance Reference      | Refers to the current object inside an instance method         | `self.name`                   |

### Simple distinction

```text
Function:
print("Hello")

Method:
"hello".upper()
```

A **function** is called independently.

A **method** belongs to an object and is called using `.`.
