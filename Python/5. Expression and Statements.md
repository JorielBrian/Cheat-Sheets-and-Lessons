## Python — Expressions vs Statements

### Expressions

An **expression** produces a value.

| Syntax                     | Name                     | Definition                               | Example                    |
| -------------------------- | ------------------------ | ---------------------------------------- | -------------------------- |
| `5 + 3`                    | Arithmetic Expression    | Calculates a value                       | `5 + 3` → `8`              |
| `x * 2`                    | Variable Expression      | Uses variables to produce a value        | `x * 2`                    |
| `x == 10`                  | Comparison Expression    | Produces `True` or `False`               | `x == 10`                  |
| `func()`                   | Function Call Expression | Calls a function and can produce a value | `len("Hello")` → `5`       |
| `"Hello" + name`           | String Expression        | Produces a string value                  | `"Hi " + name`             |
| `[x * 2 for x in numbers]` | List Comprehension       | Produces a new list                      | `[x * 2 for x in numbers]` |

### Statements

A **statement performs an action**.

| Keyword / Syntax | Name                  | Definition                             | Example              |
| ---------------- | --------------------- | -------------------------------------- | -------------------- |
| `=`              | Assignment Statement  | Assigns a value to a variable          | `x = 10`             |
| `if`             | Conditional Statement | Executes code based on a condition     | `if x > 5:`          |
| `for`            | For Loop Statement    | Repeats code for each item             | `for x in numbers:`  |
| `while`          | While Loop Statement  | Repeats while a condition is true      | `while x < 10:`      |
| `def`            | Function Definition   | Defines a function                     | `def greet():`       |
| `return`         | Return Statement      | Exits a function and returns a value   | `return x`           |
| `import`         | Import Statement      | Imports a module                       | `import random`      |
| `break`          | Break Statement       | Stops a loop                           | `break`              |
| `continue`       | Continue Statement    | Skips to the next loop iteration       | `continue`           |
| `pass`           | Pass Statement        | Does nothing; placeholder              | `pass`               |
| `class`          | Class Definition      | Defines a class                        | `class User:`        |
| `del`            | Delete Statement      | Deletes a variable, item, or attribute | `del x`              |
| `raise`          | Raise Statement       | Raises an exception                    | `raise ValueError()` |

### Simple distinction

```python
x = 10 + 5
```

* `10 + 5` → **expression** → produces `15`
* `x = ...` → **statement** → assigns that value to `x`

Think:

> **Expression = produces a value**
> **Statement = performs an action**
