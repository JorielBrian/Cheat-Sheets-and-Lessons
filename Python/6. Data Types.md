## Python — Data Types

| Keyword / Type | Name        | Definition                               | Example                       |
| -------------- | ----------- | ---------------------------------------- | ----------------------------- |
| `int`          | Integer     | Whole numbers                            | `age = 25`                    |
| `float`        | Float       | Decimal numbers                          | `price = 19.99`               |
| `complex`      | Complex     | Numbers with real and imaginary parts    | `z = 3 + 4j`                  |
| `bool`         | Boolean     | Represents `True` or `False`             | `is_active = True`            |
| `str`          | String      | Text/sequence of characters              | `name = "John"`               |
| `list`         | List        | Ordered, mutable collection              | `items = [1, 2, 3]`           |
| `tuple`        | Tuple       | Ordered, immutable collection            | `point = (10, 20)`            |
| `range`        | Range       | Represents a sequence of numbers         | `range(5)`                    |
| `dict`         | Dictionary  | Key-value collection                     | `user = {"name": "John"}`     |
| `set`          | Set         | Unordered collection of unique values    | `nums = {1, 2, 3}`            |
| `frozenset`    | Frozen Set  | Immutable set                            | `nums = frozenset({1, 2, 3})` |
| `NoneType`     | None        | Represents absence of a value            | `result = None`               |
| `bytes`        | Bytes       | Immutable sequence of bytes              | `data = b"Hello"`             |
| `bytearray`    | Byte Array  | Mutable sequence of bytes                | `data = bytearray(5)`         |
| `memoryview`   | Memory View | Provides access to memory of binary data | `memoryview(b"Hello")`        |

### Check a data type

```python
x = 25

print(type(x))
```

Output:

```text
<class 'int'>
```

### Main categories

```text
Numeric     → int, float, complex
Boolean     → bool
Text        → str
Sequence    → list, tuple, range
Mapping     → dict
Set         → set, frozenset
Binary      → bytes, bytearray, memoryview
None        → NoneType
```
