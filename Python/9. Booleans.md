## Python — Booleans

| Keyword / Syntax | Name               | Definition                                       | Example                  |
| ---------------- | ------------------ | ------------------------------------------------ | ------------------------ |
| `bool`           | Boolean Type       | Represents either `True` or `False`              | `is_active = True`       |
| `True`           | True               | Represents a true condition                      | `x = True`               |
| `False`          | False              | Represents a false condition                     | `x = False`              |
| `bool()`         | Boolean Conversion | Converts a value to `True` or `False`            | `bool(1)` → `True`       |
| `not`            | Logical NOT        | Reverses a Boolean value                         | `not True` → `False`     |
| `and`            | Logical AND        | Returns true when both conditions are true       | `True and True` → `True` |
| `or`             | Logical OR         | Returns true when at least one condition is true | `True or False` → `True` |
| `==`             | Equality           | Checks whether two values are equal              | `5 == 5` → `True`        |
| `!=`             | Inequality         | Checks whether two values are different          | `5 != 3` → `True`        |
| `>`              | Greater Than       | Checks if one value is greater                   | `10 > 5` → `True`        |
| `<`              | Less Than          | Checks if one value is smaller                   | `5 < 10` → `True`        |
| `>=`             | Greater/Equal      | Checks if value is greater or equal              | `10 >= 10` → `True`      |
| `<=`             | Less/Equal         | Checks if value is smaller or equal              | `5 <= 10` → `True`       |

### Truthy and Falsy

Python treats some values as `False` in Boolean contexts:

```python id="7n3j9k"
bool(0)       # False
bool("")      # False
bool([])      # False
bool(None)    # False
```

Most other values are **truthy**:

```python id="x9r2pb"
bool(1)       # True
bool("Hello") # True
bool([1, 2])  # True
```

This is why you can write:

```python id="kq6t4w"
name = ""

if name:
    print("Name exists")
```

Since an empty string is **falsy**, the `print()` won't execute.
