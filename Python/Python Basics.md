## Python Basics

| Keywords  | Name                | Definition                                      | Example                     |
| --------- | ------------------- | ----------------------------------------------- | --------------------------- |
| `print()` | Print function      | Displays something on the screen                | `print("Hello")`            |
| `input()` | Input function      | Gets input from the user                        | `name = input("Name: ")`    |
| `=`       | Assignment          | Assigns a value to a variable                   | `age = 25`                  |
| `def`     | Function definition | Creates a function                              | `def greet():`              |
| `return`  | Return statement    | Sends a value back from a function              | `return total`              |
| `if`      | If statement        | Runs code when a condition is true              | `if age >= 18:`             |
| `elif`    | Else-if statement   | Checks another condition                        | `elif age >= 13:`           |
| `else`    | Else statement      | Runs when previous conditions are false         | `else:`                     |
| `for`     | For loop            | Repeats code for each item                      | `for x in numbers:`         |
| `while`   | While loop          | Repeats code while a condition is true          | `while age < 18:`           |
| `in`      | Membership operator | Checks whether something exists in a collection | `"a" in "apple"`            |
| `and`     | Logical AND         | Requires both conditions to be true             | `age > 18 and age < 60`     |
| `or`      | Logical OR          | Requires at least one condition to be true      | `age < 18 or age > 60`      |
| `not`     | Logical NOT         | Reverses a condition                            | `not is_valid`              |
| `==`      | Equality operator   | Checks if two values are equal                  | `x == 10`                   |
| `!=`      | Not-equal operator  | Checks if two values are different              | `x != 10`                   |
| `>`       | Greater than        | Checks if left value is greater                 | `x > 10`                    |
| `<`       | Less than           | Checks if left value is smaller                 | `x < 10`                    |
| `>=`      | Greater/equal       | Checks if left value is greater or equal        | `x >= 18`                   |
| `<=`      | Less/equal          | Checks if left value is smaller or equal        | `x <= 18`                   |
| `#`       | Comment             | Adds a note that Python ignores                 | `# This is a comment`       |
| `import`  | Import              | Loads a module/library                          | `import random`             |
| `from`    | Import from         | Imports something specific from a module        | `from random import choice` |
| `as`      | Alias               | Gives an imported module another name           | `import random as r`        |
| `None`    | None value          | Represents the absence of a value               | `result = None`             |
| `True`    | Boolean True        | Represents a true value                         | `is_valid = True`           |
| `False`   | Boolean False       | Represents a false value                        | `is_valid = False`          |

### Basic Data Types

| Keywords | Name       | Definition                       | Example                   |
| -------- | ---------- | -------------------------------- | ------------------------- |
| `int`    | Integer    | Whole number                     | `age = 25`                |
| `float`  | Float      | Decimal number                   | `price = 19.99`           |
| `str`    | String     | Text                             | `name = "John"`           |
| `bool`   | Boolean    | `True` or `False`                | `is_online = True`        |
| `list`   | List       | Ordered, changeable collection   | `numbers = [1, 2, 3]`     |
| `tuple`  | Tuple      | Ordered, unchangeable collection | `point = (10, 20)`        |
| `dict`   | Dictionary | Key-value collection             | `user = {"name": "John"}` |
| `set`    | Set        | Collection of unique values      | `numbers = {1, 2, 3}`     |
